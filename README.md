## Описание работы
Целью данной лабораторной работы является знакомство с синтаксисом JavaScript, базовыми конструкциями (циклы, условия) и написание функций. В рамках варианта №6 реализован скрипт для анализа массива с длительностью фильмов в минутах.

## Реализованный функционал (согласно заданию)

В файле `script.js` реализована следующая логика:

1. **Ввод/вывод:** 
   - Используется `prompt()` для ввода имени пользователя.
   - Используется `alert()` для вывода приветствия и основной статистики.
   - Используется `console.log()` для вывода дополнительных расчетов и проверок.

2. **Функции для работы с массивами:**
   - `findMax(arr)` — находит максимальное значение в массиве (самый длинный фильм).
   - `filterLongMovies(arr)` — фильтрует массив, оставляя только фильмы длительностью более 120 минут (полнометражные).
   - `calculateSum(arr)` — вычисляет сумму всех элементов массива (общая длительность).

3. **Циклы и условия:**
   - Реализован цикл `for`, который проходит по исходному массиву, находит короткометражки (длительностью ≤ 40 минут) и считает их количество и суммарную длительность.
   - Реализовано условие `if`: если максимальная длительность фильма ≥ 180 минут, в консоль выводится дополнительное сообщение («Это почти как полноценный театральный спектакль!»).

## Формат вывода
*   **Alert:** Выводит имя пользователя, общую длительность всех фильмов и длительность полнометражных фильмов.
*   **Console:** Выводит количество короткометражек, их суммарную длительность и дополнительное сообщение (если сработало условие).
